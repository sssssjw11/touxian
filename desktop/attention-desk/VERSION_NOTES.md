# Attention Desk 版本改进记录

## 2026-09-26 · 官网监测与桌面体验验收版

本次记录对应当前工作区的体验重构，不自动修改 npm 包版本号。

### 已完成

- 学院来源列表支持桌面端拖动排序；“全部学院”固定在列表最上方，来源顺序保存在本机并会自动合并新来源、清理失效来源。
- 学院来源支持右键菜单置顶 / 取消置顶；置顶来源独立排在学院列表前部，图钉状态刷新后保留，点击、未读数和扫描行为不受影响。
- 官网监测保留 22 个温州大学学院公开来源，继续使用串行请求、限速和部分可用状态。
- 公告列表增加发布日期、来源、栏目、分类和分类置信度；分类固定为：
  - `competition_activity`：比赛 / 活动
  - `publicity`：公示
  - `other`：其他公告
  - `unknown`：待确认
- 新增按需公开正文读取：`GET /api/official/notice`。
- 新增官网公告独立完成状态：`POST /api/official/action`。
- `read`、`completed`、认证状态和正文读取失败互相独立，不用一个布尔值覆盖多个含义。
- 官网工作台增加分类筛选、发布日期范围、搜索、“全部 / 未读 / 已读完”、详情抽屉、正文摘要、证据提示和完成/撤销完成。
- 截止日期解析支持明确关键词、时间格式和“9月7日至9月28日送交材料，逾期不再受理”这类日期区间，区间结束日作为截止日。
- 删除过宽的独立“于”日期匹配，避免把“公告发布于 2026 年……”或版本号误判为截止日期。
- 详情读取仅访问温州大学公开域名，不下载图片和附件；认证墙、非官方跳转、空正文和 HTTP 失败均给出明确错误。
- 桌面字号、线性图标、键盘焦点、120–200ms 轻量过渡和 `prefers-reduced-motion` 已纳入官网工作台。
- README 与产品需求文档已同步到实际接口和当前行为。

- 控制台没有应用错误或警告；仅保留 React DevTools 的开发提示信息。
- 接口负向烟测通过：`GET /api/official/overview` 返回 200；非温大详情地址、非法提醒间隔、缺失公告操作均返回明确的 400 错误。

### 已知改进点

- 目前只完成 Chromium / Chrome 浏览器验收，Firefox、WebKit 和原生桌面封装尚未单独回归。
- 测试工作区已有持久化提醒设置为每 6 小时；全新状态文件的代码默认仍为每 12 小时，自动检查只在完成首次全量检查后计时。
- 当前自动提醒仍是本地检查，不会未经确认自动发邮件或外部通知，邮件摘要仍需手动触发。
- 官网正文容器因不同学院模板存在差异，个别页面可能需要增加容器选择器；遇到失败应显示原因而不是静默归零。
- 跨来源统一行动队列和远程 Jev / 用户画像的误判样本校准仍属于后续版本，不在本轮改变最终优先级规则。
