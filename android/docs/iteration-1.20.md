# 偷闲 1.20 迭代记录

## 本轮目标

- 修复微信会话标题被“本地热搜头条”等顶部横幅抢占的问题。
- 降低个人聊天中排名、失落和普通闲聊被事件监测误判的风险。
- 识别“视频提交时间28号下午5点截止”这类省略月份的截止表达。
- 结合会话名补全“黑客松”等事件类型。
- 将应用可见名称统一为“偷闲”。

## 实现

- 微信 ActionBar 标题节点 `com.tencent.mm:id/obn` 优先于通用文本扫描。
- 通用标题候选限定在 ActionBar 区域，并过滤热搜、头条、广告、推广等横幅词。
- 标题节点未暴露时，仅在重复一致且没有群聊信号的个人头像标签下辅助确认；不同头像不会被当成群名。
- 截止解析器支持近期开出的日号表达，并按消息日期解析月份，避免把房间号等普通数字当截止日期。
- 事件类别同时参考可见消息和会话名称，黑客松归入“竞赛”。

## 验证

- WeChatAdapter、DeadlineParser、AttentionEngine 定向测试通过。
- APK `assembleDebug` 构建通过，包内规则校验通过。
- 打包时设备端 ADB 未发现已连接设备；2026-09-27 已在重新连接的真机覆盖安装 1.20 并完成定向测试。
