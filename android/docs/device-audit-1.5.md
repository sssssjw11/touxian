# Attention Guard 1.5 真机审计

审计日期：2026-09-22

## 环境

- 设备：小米 Android 17
- 微信：8.0.78
- 连接方式：ADB
- 测试范围：仅使用一个获得授权的测试会话；仓库不记录会话名称、聊天正文或截图
- 行为边界：不发送消息、不写入微信输入框、不上传聊天内容、不启用联网增强

## 已实际观察

1. 当前可见微信气泡节点可以被读取，并能写入本机消息归档。
2. 诊断页可以显示节点读取、结构匹配和落盘状态。
3. 1.4 的悬浮窗收起态过窄，部分文字按钮被裁切；透明度过低时微信正文会穿透。
4. 仅显示“无障碍已授权”不足以说明服务正在运行；服务断开后需要单独表达心跳失效。
5. 回溯入口层级较深，准备任务后需要明确回到目标微信会话确认开始。

## 1.5 已落地修正

- 收起态保留拖动、暂停/继续和回溯入口，窗口约束到系统栏边界。
- 悬浮层透明度收紧到可读范围，避免聊天文字穿透。
- 采集工作区拆为“回溯 / 记录 / 诊断”三个页签。
- 准备回溯后锁定配置，并提供“返回微信确认开始”。
- 运行健康拆分为系统授权、服务连接和心跳过期三类状态。
- 日期解析增加日历合法性、中文时段和歧义日期校验；P0 必须满足本地证据门槛。
- 消息归档增加短时同屏检查点，减少服务重连后的重复插入。

- Android lint：0 errors，39 warnings
- Debug APK：签名校验与 16KB zipalign 检查通过
