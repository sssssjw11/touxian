# 偷闲 1.25.2：悬浮卡闪烁、滑动群名与事件卡片屏闪修复

日期：2026-10-01。基线：1.25 / versionCode 26；目标：1.25.2 / versionCode 27。保留 1.25 的数据、规则与会话范围。

## 现场依据

- 用户两段录屏（微信 8.0.78，Android 17，偷闲 1.25）：
  - 「AIGCxWZU丨温州大学(225)」：屏幕群名清晰，悬浮卡在「气泡可读，但会话名称未确认」与 OCR 群名之间来回切换。
  - 「Attention Is All You Need(5)」：上下滑动时悬浮卡反复消失、重现。
- 真机诊断 `pipeline`：00:35–00:41 间 `TITLE_OCR STARTED → OUT_OF_SCOPE` 每约 10 秒一次，连续数十次；滑动时出现 0.5 秒间隔的 `STARTED → PAGE_CHANGED`。
- 观测词条中没有「AIGCxWZU…」，有「Attention Is All You Need」。前者不识别属预期范围限制，但不应反复截屏和闪烁。

## 根因

| 现象 | 原因 |
| --- | --- |
| 群名在「未确认」和真实群名之间跳动 | OCR 读到词条外群名后不保存结果；下一次 1.5 秒轮询标题节点仍为空，退回「未确认」，10 秒后再 OCR，循环 |
| 每次 OCR 悬浮卡都闪一下 | 标题截屏前无条件把悬浮卡设为不可见，而卡片默认位于顶部栏下方，本不遮挡标题 |
| 滑动时反复闪 | 滑动中每帧消息签名都在变；OCR 完成时判定「页面已变化」，500 毫秒后重试，再次隐藏悬浮卡 |
| 标题恢复时卡片闪烁 | 会话标题从空变为已识别，`invalidate()` 移除悬浮窗再重新挂载，触发入场动画 |
| 标题节点单帧为空 | 列表滚动时微信标题节点可能短暂为空，卡片立即切换为「未确认」再切回 |

## 修复

- 词条外的 OCR 群名作为仅显示用绑定保存，沿用可信消息重叠校验；同一聊天不再重复截屏。它不写入消息、不创建事件、不能用于标记；修改词条或切换页面后失效并重新核对。
- 标题截屏只在悬浮卡与实际顶部栏范围重叠时隐藏卡片；无法测得范围时保持原有隐藏行为。
- 自动标题 OCR 需当前消息画面稳定 600 毫秒后才开始，滑动期间不截屏；停止后通过定时回调补发，不依赖下一次轮询。
- 会话标题变化时原地更新已挂载的悬浮卡，不移除窗口；离开微信、关闭观测等仍按原逻辑隐藏。
- 已确认的会话在同一窗口内滑动时保持已确认，见下节。

## 滑动后短暂显示「未确认」

用户追问：已进入并识别成功的群，只是上下滑动、群名位置没变，为什么仍会闪「会话未识别」。

原因是会话身份每一帧都重新证明。群名节点为空时，只能靠「新一屏与上一屏有足够长、足够独特的消息重叠」继承群名；短回复、表情、语音或一次滑过整屏就没有重叠，该帧立刻判为「未确认」，再等 OCR 恢复。滑动本身被当成了可能换群的证据。

修复后区分两种证据：

- **核对**：可读群名、可信消息重叠或后台 OCR 读到同名。只有核对过的画面才写入消息和事件，与此前一致。
- **延续**：同一窗口、上次核对后没有页面切换事件、没有离开微信、没有出现非聊天页，只是列表内容变了。延续画面继续显示已确认群名和当前可见条数，但不写入；停止滑动 600 毫秒后后台 OCR 核对，同名即补存当前画面。

延续在以下情况立即结束：微信 `WINDOW_STATE_CHANGED`、离开微信或锁屏、出现无气泡页面、顶部读到另一个群名、后台 OCR 读到另一个词条外的群名。同一窗口滑动不再累计「失败页」，因此不会因连续翻过三屏而丢失绑定；导航后仍按原规则三次不同失败页失效。

诊断 `pipeline` 新增 `TITLE_BIND`（仅元数据）：`CONTINUED`、`NAV_PAUSE`/`PANE_PAUSE`（页面或弹层切换打断）、`NO_CHAT_PAUSE`、`CONFLICT_ID`/`CONFLICT_SCAN`、`EXPIRED`、`OCR_CONFLICT`，用于判断真机上是哪种证据打断了延续。

## 事件卡片切换时屏闪

用户反馈：群名识别已正常，但事件检测成功、切换新事件时悬浮窗屏闪；希望像意图分析一样只变文字。

原因：同一个群每换一屏，`acceptSnapshot` 都先把卡片重置为「已识别 N 条可见消息」空闲样式，约 100 毫秒后本地事件保存完成，`analyzeLocal` 再展开事件详情。两种样式高度不同，窗口随之缩放。意图分析没有这个中间态。

修复：

- 新增 `showStatus`：卡片正在显示本群事件时，新画面只更新状态文字，不经过空闲样式；换群、进入回溯时仍切回空闲样式。滑动延续画面同样处理。
- 同一群、同一尺寸与菜单状态下替换事件，卡片高度只增不减，避免窗口缩放。
- 取消未完成的云端整理时清除「整理中」标签，避免保留的事件卡片停在该状态。

## 边界

- 「AIGCxWZU丨温州大学(225)」不在观测词条内，本版只让卡片稳定显示「会话未匹配观测范围」，不会自动开始识别；需要时请用「标记当前微信会话」加入。
- 悬浮卡被拖到顶部栏上时，标题截屏仍会短暂隐藏卡片，以免把卡片内容识别成群名。
- 延续只影响显示。关闭本机 OCR 且群名节点为空时，无重叠的滑动画面仍不会写入，直到回到有重叠的画面或群名可读。
- 若微信在滑动时发出页面切换事件，延续仍会被打断；此时诊断会记录 `NAV_PAUSE` 或 `PANE_PAUSE`，需据此再调整。
- OCR 把已加入词条的群名误读成另一个名字时，会按「另一个群」处理并显示未匹配；可重新标记当前会话。
