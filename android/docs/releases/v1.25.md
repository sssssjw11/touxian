## 更新内容

### 自定义消息正文关键词

- 微信入口：「事件监测 → 更多 → 消息关键词」；APP 入口：「规则与外观 → 消息正文关键词」。
- 支持新增、编辑、启停、确认删除；每条可配置事件类型和 P0–P3 重要性，最多 100 条，编辑草稿可跨旋转保留。
- 会话名称词条决定观测范围，正文关键词决定哪些消息需要整理，两套配置独立。
- 字面匹配、全半角规范化、大小写规范化与英文单词边界；不把用户输入执行为正则。
- 只匹配对方原生文字正文，不匹配群名、发送者、自发消息或未核对 OCR 正文。
- 保存规则后重新分析当前页，沿用既有事件 ID，不另建重复事件路径。事件详情保存「消息关键词命中」依据。
- 用户自定义类型和重要性不被云端分析覆盖；普通信息进入持续观测，有明确行动才成为待办。取消、完成、过期不会升级紧急提醒。
- 停用或删除规则不删除之前保存的事件，也不扩大已选择的会话范围。

### 群名与滑动恢复

- 直接读到完整标题、手动标记当前会话时均建立标题绑定，保留后续可信重叠页的连续性。
- 同一失败页面的重复轮询不再累计为多个不同页面失败，避免短时间误释放绑定。
- 在事件监测、气泡可读但标题缺失且已开启本机 OCR 时，按实际顶部栏范围限频恢复标题；只接受当前页面、新鲜截图和范围匹配的完整结果。
- OCR 按位置重组数字、英文和中文片段，排除日期、导航、纯数字和省略标题；不再按最长一行猜群名。
- 离开聊天、切模式或页面变化使旧请求失效；不从词条列表或气泡昵称猜当前会话，也不仅凭窗口 ID 复用群名。

### 单会话记录与关系深度分析

- 微信意图模式保持默认不记录、不自动创建事件；显式开始会话记录后，才保存读到的可见消息及自行翻页的片段。
- 切页面、离开微信、锁屏、切模式及重启暂停记录，回到目标会话后需确认继续；不自动追踪另一个聊天。
- APP「会话分析」按消息日期选择范围，未知日期单列，保留原文、全量统计、关键语境与可追溯证据。
- 借鉴 [she-love-me](https://github.com/863401402/she-love-me) 的全量统计与关键窗口方法，分开双方、多人、情绪与关系态度；边界表达、单侧及少量样本不强行解释成亲近。
- 可选 DeepSeek 深化需在 APP 单独确认；发送所选范围统计和最多 90 条关键消息，每条最多 2,000 字符。失败保留本地报告，引用必须来自输入原话，不允许编造证据。
- 不把采集时间当发送时间，不伪造回复延迟或被爱概率。新消息使旧报告失效，避免显示与当前选择不一致的结果。

### 入库、诊断与交互

- 意图模式更多菜单增加「保存当前事项」，不隐式切换模式；自动事件监测与手动保存保持独立。
- 修复保存后立即打开 APP 导致任务失效、事件稍晚落盘但已打开列表未更新的问题；悬浮窗使用实际合并保存后的事件状态，不把已完成或归档事项假装成新待办。
- APP「采集与回溯 → 诊断 → 导出诊断报告」通过系统文件选择器导出 JSON，无需额外文件存储权限。
- 诊断含版本、权限事实、服务心跳、数量、最近 80 条阶段元数据，可区分未创建、写入失败、筛选隐藏和示例模式；不含聊天正文、会话名、截图、用户关键词内容或 API Key。
- 复用共享字体、图标和短动效，保留悬浮窗半屏宽上限。意图面板录制、刷新、更多保持紧凑，菜单与详情不同时堆叠；禁用系统动画时不继续按压缩放。

## Debug：现象、原因与修复

| 现象 | 确认的原因 | 本版处理 |
| --- | --- | --- |
| 已加入会话词条仍识别不到 | 真机上词条存在、服务有心跳、气泡可读，但微信顶部标题节点有时为空；名称校验先于词条匹配失败，不是词条没保存 | 增加标题绑定与限频本机标题 OCR，明确区分空群名与范围未匹配 |
| 第一次能识别，滚动后失败 | 完整翻页可能失去消息重叠；原绑定还将同一失败页的重复轮询当成多个失败 | 按不同页面签名计数、可信重叠恢复后清零；不重叠时重新核对标题 |
| 识别了但 APP 没出现 | 部分反馈发生在不自动写事件的意图模式；另有事件异步落盘与列表刷新竞态 | 保持模式边界，增加显式保存事项、写入阶段诊断和列表自动刷新 |
| 已完成、否定或引用被当新任务 | 关键词和行动词可能出现在否定、引用或同条消息的另一主题里 | 修复行动否定、无关引用、取消主题抢占有效任务及过期 P3 被升级的问题 |
| 情绪与关系判断互相覆盖 | 自己、不同成员或他人的关闭语句可能影响当前对方；重复同词让评分过早饱和 | 分开证据归属，处理问句/否定/引用，上下文按距离衰减；评分不是校准概率 |
| 编辑关键词第一次保存无效的竞态 | 保存监听依赖异步 OnShow，框架回调尚未执行就可能点击 | show 后立即绑定；新增不等待回调的首击保存测试 |

消息匹配、会话身份、模式、事件保存分别处理，不能用“放宽群名校验”掩盖采集失败，也不能用“增加关键词”掩盖语义问题。

## 怎么提供有效诊断

1. 记录偷闲版本、微信版本、Android 版本、手机型号与当前模式。
2. 保留最短复现步骤，例如「进入聊天正常 → 向上翻一屏 → 不再识别」；标明预期结果和实际结果。
3. 在诊断页核对连接、心跳、标题读取、文字数量、本地判定、事件保存和列表筛选。
4. 导出诊断 JSON，检查后附到 Issue。正文必要时另给匿名最小样例，不上传完整聊天、私人截图或密钥。

排查顺序：

```text
服务连接/权限 → 前台页面 → 气泡与标题 → 会话范围
→ 当前模式/是否自动分析 → 规则判定 → 本地事件写入 → APP 筛选/刷新
```

- 气泡可读而标题为空：先解决会话来源，不反复添加同一个词条。
- 标题正确而没有事件：检查消息是否属于闲聊、是否命中正文规则及有无行动要求，不把“没有事项”当成“没有读到群”。
- 意图模式未显式保存：没有新事件是预期边界，不应通过额外存储权限解决。
- 写入成功但列表看不到：先清理检索条件、查看完成/归档筛选，确认没有处于示例模式，不先清空应用数据。

## 验证与边界

- 发布前 21 个受影响测试类共 **296 项** JUnit / Robolectric 回归通过，失败 0、错误 0；覆盖消息规则、意图与事件、关系报告、存储、标题/OCR、服务、页面、诊断及悬浮窗。
- APK 构建、包内规则标记、签名和版本核对通过，1.25 / versionCode 26 已覆盖安装真机。公开下载按上方 SHA-256 校验。
- 现场标题问题：微信 8.0.78 下已观察到可读气泡但标题节点为空的状态。修复后连续 6 次滚动均保持监测；这 6 个检查点的原生标题都可读，**不是 6 次真实 OCR 恢复测试**。
- 正文关键词真机测试：仅标题含临时关键词而正文不含时未触发；对方正文命中时生成一件教务/行政、P2、持续观测事项，保存并在 APP 显示依据。最终包再次核对展示、编辑保存与确认删除，临时规则已清理，原数据保留。
- 标题为空后的真实 OCR 恢复、同名会话、长时间录制、跨机型、后台、系统导出完整交互仍需进一步验收；代码测试不能代替这些真机结果。
- 没有发送微信消息、操作真实日历或归档用户事件。DeepSeek 格式和证据约束使用模拟网络测试，未把私人聊天发往外部模型。
- 各轮测试存在重叠，本次 296 项不与此前 212、98、61 等数量累加，不据此宣称任意聊天识别准确率。
