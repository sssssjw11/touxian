# 偷闲 1.22 预览版

面向微信当前可见会话的事件整理与持续意图分析。此版本为 **debug 签名预览包**，不是稳定版发布承诺。

## 下载

- `touxian-1.22-debug.apk`：Android 11 / API 30 及以上，versionCode 23。
- `touxian-1.22-debug.apk.sha256`：安装包完整性校验。
- 包名保持 `com.attentionguard.app`，可优先尝试同签名覆盖安装。

```text
6315c32c540cdaa2f8f6683f1824fec83f163181473467a5d5ba21968252b640  touxian-1.22-debug.apk
```

签名不一致时请先确认数据保留方案，不要直接卸载。卸载会删除本机应用数据。

## 这次带来什么

- 事件监测、持续意图分析与自由文本分析明确分离。
- 微信标准文字表情及常见 Unicode 表情不再漏掉；表情线索保留较低把握度，重复表情不堆高分数。
- 不把自己或已知其他群成员的情绪归入当前发言者，上文证据按真实距离衰减。
- 改善群名来源、手动确认、会话连续性、词条标准化及截断名称处理。
- 修复正文类别被群名覆盖、未知日期猜月份、过去期限滚向未来等判断问题。
- 悬浮窗支持完整面板、紧凑工具条和小球；优化菜单、重绘与点击恢复。
- 观测簿支持时间 / 重要性组合检索、快捷完成、全选与批量归档。
- 日历预览保留用户确认；记住目标日历，仅有日期时默认 10:00，提醒默认开始时。

## 验证

- 136 项针对性功能回归通过；已安装 APK 的 19 项设备端规则检查通过。
- 公开样例去标识后另有 66 项相关回归通过，不与上述数量简单相加。
- 真机为 Xiaomi 25098PN5AC / Android 17 / 微信 8.0.78。
- 已验证标准愤怒表情线索、悬浮窗恢复与菜单、批量全选及退出；没有发送微信消息或实际归档用户事件。

## 尚未解决的边界

群名不可读时的完整回退确认流程仍待真机验收。任意图片表情、反讽与复杂语境不保证准确；置信度为规则评分，不是统计概率。仅对当前可见会话生效，不后台扫描全部群聊。可选 DeepSeek 事件增强会向外部服务发送必要内容，默认关闭。

完整功能、权限与安装说明见仓库 README；细节见 `docs/device-acceptance-1.22.md`。
