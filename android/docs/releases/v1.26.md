## 覆盖安装

交付文件：偷闲-1.26-WeChat.apk，debug 签名。包名 com.attentionguard.app，最低 Android 11。

    adb install -r "偷闲-1.26-WeChat.apk"

同签名的 1.25.2 可以覆盖升级，数据库自动迁移到版本 4，保留原录制、消息与报告。无需卸载或清除数据。若此前使用其他签名，Android 的签名限制仍然适用。

## 构建

    .\gradlew.bat :app:testDebugUnitTest :app:assembleDebug

可离线构建需要已有 Android SDK 和 Gradle 依赖缓存。校验文件为 touxian-1.26-debug.apk.sha256。
